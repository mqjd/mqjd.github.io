put up with

2026-11-14 — 高中

核心释义

Section titled “核心释义”

put up with phr. BrE IPA not found · AmE IPA not found

  1. to accept somebody/something that is annoying, unpleasant, etc. without complaining

词源拆解

Section titled “词源拆解”

由高频基本动词 put 与小品词 up、介词 with 组合而成，借“在某处安顿下来并与之共处”的空间与生活隐喻，演化为对不便或讨厌之物的“忍受、容忍”。

  • 核心词源：put 源自中古英语 putten 及晚期古英语 *putian（推、戳、放置，移动物体并安置到某处），与古英语 pytan（推出）及北欧、荷兰语等日耳曼语同源词相关。

  • 介词/副词逻辑：up 源自古英语 up（原始日耳曼语 *upp-，原始印欧语 *upo），既有“向上”的方向义，也在日耳曼短语动词中常表“收起、安顿好”；with 源自古英语 wið（原义“相对、迎面”，原始日耳曼语 *withro-），到中古英语逐渐转为“伴随、与……共存”的关系义。

  • 隐喻融合：put up with 始见于 1755 年，学界普遍认为其可能由 1727 年已出现的 put up（“落脚投宿、安顿下来”）或“收进口袋、隐忍不发”的用法引申而来——在空间与处境隐喻上，一旦你在某处“安顿下来”（put up）并“伴随某人或某种烦扰”（with），便不得不接受现实、不加抱怨地忍受下去。

快速记忆

Section titled “快速记忆”

💡 把 put up（安置、留宿）与 with（一起共处）连起来想：家里不得不留宿一位难缠的客人并与之共处（put up with），自然只能“忍受、容忍”。

词族对比

Section titled “词族对比”

  • put：短语核心动词，原义为“推、放、置”，与不同小品词搭配可构成大量短语动词，是 put up with 的核心动作基础。

  • put-upon：由短语 put upon（欺骗、强加负担）转化而来的非正式形容词，形容人因脾气好或乐于助人而“受委屈的、被人欺负利用的”。

  • off-putting：由短语 put off（使反感、推迟）派生的形容词，指言行、外表或气味“令人反感的、倒胃口的、令人生畏的”。

  • put-down：由短语 put down 转化而来的非正式名词，指“当众贬低、羞辱或挖苦他人的言行”。

  • input：由 in- 与 put 复合而成的常用名词与动词（14 世纪末起见载），字面为“放进去”，现指“投入的资源、意见”或“（数据、信息）输入”。

高频搭配

Section titled “高频搭配”

  • put up with the noise / mess / traffic：接令人烦躁的环境或生活困扰名词，表示忍受噪音、脏乱或交通拥堵。

  • put up with sb.’s behaviour / nonsense / attitude：接他人的不当言行或态度，表示容忍某人的坏脾气、胡说八道或恶劣表现。

  • can’t / refuse to / won’t put up with …：高频否定句式，常接名词或动名词（putting up with doing sth.），强烈表达“受够了、绝不容忍”。

  • have (got) to put up with …：高频情态表达，凸显因条件所限而“不得不勉强忍受、凑合承受”（如 a lot to put up with）。

同义词

Section titled “同义词”

以下对比均针对 put up with 的“容忍、忍受”义。

  • tolerate v. — 语体更正式，侧重克制反感予以容许

    put up with 偏口语与日常感，常指无奈地接受烦心事；tolerate 属于较正式的单一动词，适用书面与口语多种场合，强调克制想要抵制、回避或怨恨的冲动，常用于规章制度、原则底线或人际包容。

  • endure v. — 强调在长期苦难或考验中坚忍撑住

    put up with 多针对日常生活中的烦扰、不便或他人毛病；endure 书面和庄重色彩更浓，侧重面对持久的痛苦、逆境或打击时坚定不屈地承受下来。

  • stand v. — 多见于否定或疑问句，强调忍住不动摇不失态

    put up with 肯定、否定句均高频使用，侧重不加抱怨地接受；stand 在“忍受”义项下最常见于 can't stand 等否定或疑问句式，更强调能否承受住刺激而不崩溃或失态。

反义词

Section titled “反义词”

以下对比均针对 put up with 的“容忍、忍受”义。

  • reject v. — 无奈接受容忍 ↔ 明确拒绝排斥

    put up with 指即便心里不喜欢或感到不适，仍选择默默接受并继续相处；reject 处于直接对立面，表示明确回绝、不予接纳或予以抵制。

  • prohibit v. — 姑息容忍 ↔ 明确禁止

    put up with 对令人不满的言行或状况采取听之任之的态度；prohibit 则以规则、权威或法令明确加以禁止，绝不允许其存在或发生。

  • prevent v. — 事后忍受承担 ↔ 事先拦截制止

    put up with 往往意味著不加阻拦或无力改变而继续承受某种行为；prevent 则处于相反一端，表示采取积极干预措施阻止不良行为或状况发生。
