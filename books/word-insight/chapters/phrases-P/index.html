核心释义

Section titled “核心释义”

put forward phr. BrE IPA not found · AmE IPA not found

  1. to suggest something for discussion

  2. to move something to an earlier time or date

  3. to move the hands of a clock to the correct later time

词源拆解

Section titled “词源拆解”

由高频基本动词 put 与方向副词 forward 组合而成，借“将人或物推到前方显眼位置”的空间意象，分别衍生出“把方案或人选摆上台面”的议事隐喻，以及“沿时间轴向前挪动”的日程与时钟义项。

  • 核心词源：put 源自中古英语 putten 及晚期古英语 *putian（推、戳、把某物移动安置到某处），与古英语 pytan（推出）及北欧、荷兰语等日耳曼语同源词相关。

  • 介词/副词逻辑：forward 源自古英语 forewearde（朝向前方、在前面；亦指指向未来或开端），由 fore（在前）与方向后缀 -ward（朝向……）构成，关联原始印欧语词根 *per-（向前、穿过）。

  • 隐喻融合：物理上“把某物往前推放、摆到众人面前”——在议事与交际隐喻中，将想法、论点或候选人名字“推到台前”供人审视讨论，于 19 世纪中期定型为“提出（建议、主张）、提名（人选）”；而在时间线隐喻中，朝时间前方推动则表现为把既定活动“提前”，以及把时钟指针“拨快”。

词族对比

Section titled “词族对比”

  • put：短语核心动词，基本义为“推、放、置”，在言语与议事语境中本身也常表示“表达、陈述”（如 put a case / question）。

  • input：由 in- 与 put 复合而成的常用名词与动词，指“投入的资源、意见建议”或“（数据）输入”。

  • output：由 out- 与 put 复合而成的常用名词与动词，指“产量、输出总量”或“输出（产品、信息）”。

  • put-upon：由短语 put upon（欺负、强加负担）转化而来的形容词，形容人因性情温顺或乐于配合而“受委屈的、被人占便宜的”。

高频搭配

Section titled “高频搭配”

  • put forward a proposal / plan / suggestion / idea：最常用的核心搭配，表示在会议、谈判或公共讨论中“提出方案、计划、建议或构想”。

  • put forward a theory / argument / explanation：学术与论证语境高频搭配，指“提出理论、论据或解释”（常用于被动态 be put forward）。

同义词

Section titled “同义词”

以下对比均针对 put forward 的“提出（计划、意见或人选）供审议”义。

  • propose v. — 语体略正式且直接，亦常用于正式动议或求婚

    put forward 在讨论与新闻报道中自然通用；propose 是最核心的单一对应动词，语义更直接正式，除提出方案与人选外，还常用于议会正式提出动议或表示“求婚”。

  • submit v. — 强调正式呈交上级或权威机构审批裁决

    put forward 重在把想法摆出来供各方讨论考虑；submit 带有明显的“正式递交、呈报”色彩，通常指把报告、申请、提案或候选名单呈送给有权审批或裁定的机构与个人。

  • put forth phr. — 偏书面或美式表达，文雅色彩更强

    put forward 在英美日常与书面语中均极高频（英式尤常见）；put forth（在词典中常标为美式对应形式）书面或文学色彩更浓，除表示“提出观点或法案”外，还可指植物“抽出新芽”或人“施展全力”。

词源拆解

Section titled “词源拆解”

由高频基本动词 put 与空间副词 out 组合而成，借“向外推放、移出界外”的物理动作隐喻，分别演化出“熄灭”“发布产出”与“打扰使不便”等核心义项。

  • 核心词源：put 源自中古英语 putten 及晚期古英语 *putian（推、戳、放置，移动物体并安置到某处），与古英语 pytan（推出，如 pytan ut “挖出、推出”）及日耳曼语同源词相关。

  • 介词/副词逻辑：out 源自古英语 ūt（向外、在外面），可追溯至原始日耳曼语 *ūt- 与原始印欧语词根 *uidh-（向上、向外）；除表示“由内向外的空间移动”外，在中古至近代早期便已独立发展出“归于熄灭”（c. 1400）、“进入公众视野”（1540s）及“偏离正常心神状态”（1580s）等方向隐喻义。

  • 隐喻融合：物理上将物体“向外推置”（如把杂物摆到门外），一方面结合“将火焰或光亮驱离、耗尽”的意象于 16 世纪 20 年代固化为“熄灭”；另一方面借“推向外部公众空间”的通道隐喻衍生出“发布、生产”；而将人“推出平稳正常的心境或状态”，则先后演化出“心神失措”（1580s）与“让人费事、感到恼火”（19 世纪）的用法。

Section titled “词源拆解”

由高频基本动词 put 与空间副词 up 组合而成，借“向上推放、使直立并安顿到位”的空间与动作隐喻，衍生出“搭建”“张贴”“涨价”与“留宿”等一系列常见义项。

  • 隐喻融合：由“向上推放、使之直立”这一具体动作，自然衍生出“搭建起（建筑、帐篷、围栏）”“高挂张贴（告示、窗帘）”及“抬高（价格、手、伞）”；而“留宿、寄宿”（1727 年见载作不及物 put up，1766 年见载作及物 put someone up）则源于旅客卸下行囊安顿住下、或由主人将其“安顿留宿”的生活空间隐喻。

Section titled “词源拆解”

由高频基本动词 put 与小品词 up、介词 with 组合而成，借“在某处安顿下来并与之共处”的空间与生活隐喻，演化为对不便或讨厌之物的“忍受、容忍”。

  • 核心词源：put 源自中古英语 putten 及晚期古英语 *putian（推、戳、放置，移动物体并安置到某处），与古英语 pytan（推出）及北欧、荷兰语等日耳曼语同源词相关。

  • 隐喻融合：put up with 始见于 1755 年，学界普遍认为其可能由 1727 年已出现的 put up（“落脚投宿、安顿下来”）或“收进口袋、隐忍不发”的用法引申而来——在空间与处境隐喻上，一旦你在某处“安顿下来”（put up）并“伴随某人或某种烦扰”（with），便不得不接受现实、不加抱怨地忍受下去。

高频搭配

Section titled “高频搭配”

  • put up with the noise / mess / traffic：接令人烦躁的环境或生活困扰名词，表示忍受噪音、脏乱或交通拥堵。

  • put up with sb.’s behaviour / nonsense / attitude：接他人的不当言行或态度，表示容忍某人的坏脾气、胡说八道或恶劣表现。

  • can’t / refuse to / won’t put up with …：高频否定句式，常接名词或动名词（putting up with doing sth.），强烈表达“受够了、绝不容忍”。

  • have (got) to put up with …：高频情态表达，凸显因条件所限而“不得不勉强忍受、凑合承受”（如 a lot to put up with）。

同义词

Section titled “同义词”

以下对比均针对 put up with 的“容忍、忍受”义。

  • tolerate v. — 语体更正式，侧重克制反感予以容许

    put up with 偏口语与日常感，常指无奈地接受烦心事；tolerate 属于较正式的单一动词，适用书面与口语多种场合，强调克制想要抵制、回避或怨恨的冲动，常用于规章制度、原则底线或人际包容。

  • endure v. — 强调在长期苦难或考验中坚忍撑住

    put up with 多针对日常生活中的烦扰、不便或他人毛病；endure 书面和庄重色彩更浓，侧重面对持久的痛苦、逆境或打击时坚定不屈地承受下来。

  • stand v. — 多见于否定或疑问句，强调忍住不动摇不失态

    put up with 肯定、否定句均高频使用，侧重不加抱怨地接受；stand 在“忍受”义项下最常见于 can't stand 等否定或疑问句式，更强调能否承受住刺激而不崩溃或失态。

反义词

Section titled “反义词”

以下对比均针对 put up with 的“容忍、忍受”义。

  • reject v. — 无奈接受容忍 ↔ 明确拒绝排斥

    put up with 指即便心里不喜欢或感到不适，仍选择默默接受并继续相处；reject 处于直接对立面，表示明确回绝、不予接纳或予以抵制。

  • prohibit v. — 姑息容忍 ↔ 明确禁止

    put up with 对令人不满的言行或状况采取听之任之的态度；prohibit 则以规则、权威或法令明确加以禁止，绝不允许其存在或发生。

  • prevent v. — 事后忍受承担 ↔ 事先拦截制止

    put up with 往往意味著不加阻拦或无力改变而继续承受某种行为；prevent 则处于相反一端，表示采取积极干预措施阻止不良行为或状况发生。
